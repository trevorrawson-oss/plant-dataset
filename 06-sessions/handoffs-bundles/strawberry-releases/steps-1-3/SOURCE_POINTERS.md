This is a starter lead list of the kind of T1 (university extension / USDA / peer-reviewed) publications strawberry guidance lives in. **claude.ai verifies, fetches, and admits each one itself** -- do not cite from this list without checking the live page. Seed-company / almanac sources are T2 (evidence-log corroboration only, never a dataset citation).

## Why strawberry sourcing forks by region (carry into Step 4)
Strawberry guidance splits by the growing model, and the regions resolve to different ones:
- **Northern matted-row PERENNIAL** -- Cornell, UMass, Minnesota, Penn State, Michigan State, Ohio State, Maryland. These carry the matted-row + renovation + June-bearing content that is the SPINE.
- **CA / FL ANNUAL plasticulture (day-neutral / winter annual)** -- UC ANR / UC IPM (California day-neutral + annual systems), UF/IFAS (Florida winter-annual plasticulture). These anchor the `grown_as: annual` cells.
- **Type biology (June-bearing / everbearing / day-neutral)** -- Oregon State, Utah State, and the above all carry the type explainer that feeds the elevated type section + the variety `type` tags.
