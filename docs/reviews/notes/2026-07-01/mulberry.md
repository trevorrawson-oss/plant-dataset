## Pollination (the headline refit vs peach)
`self_fertile = true`, `pollination.needs_pollinizer = false`, `pollinizer_distance_ft = null`.
- **Most cultivated / named mulberries are SELF-FRUITFUL, and many are PARTHENOCARPIC** (set fruit
  with no pollination, often seedless), so a single named tree bears heavily on its own. Pollination
  is by **wind**, not insects, so pollinators are not needed for set (the good_seasoned companion
  entry is labeled traditional/low precisely because of this).
- **Dioecious caveat (kept honest and prominent):** at the species level some wild mulberries are
  dioecious (male and female flowers on separate trees) or monoecious, so an unnamed seedling can be
  a non-fruiting male. The guidance throughout (pollinator_notes, varieties.note, failure_diagnostic
  `mulberry_fd_no_fruit`, companions note) is: buy a NAMED fruiting cultivar (Illinois Everbearing,
  Dwarf Everbearing, Silk Hope, etc.), not an unnamed seedling. This is the inverse of many apples
  (which require cross-pollination) and of peach (self-fertile but insect-pollinated).

## Hardiness by species (the region refit vs peach)
`hardiness_zone_min = 4`, `hardiness_zone_max = 11`; `reliable_fruit_zone 4-10`.
- **White mulberry (M. alba)** + hardy hybrids (Illinois Everbearing, Silk Hope): cold-hardy ~z4-5
  and up (Illinois Everbearing to about -20 F). [ncsu_ext: morus-alba z4-8; illinois-everbearing z4-9]
- **Red mulberry (M. rubra)**, the native: ~z4-9. [ncsu_ext: morus-rubra z4-9]
- **Black mulberry (M. nigra)** + low-chill types: tender, warm-climate ~z7-10 and into the
  subtropics; smaller/bush-like. [uf_ifas]
- **Key divergence from peach:** mulberry is LOW-CHILL, so it is NOT chill-limited at the warm edge
  the way peach is (peach ships empty `survives_no_fruit` calendars in z10/z11). Mulberry fruits
  across the warm/tropical zones. Region model: z3 = `unsuitable` (cold limit, empty calendar); z4 +
  the warm/low-chill extremes (ca_south_coast z10, ca_desert z10, low_desert_az z9, fl z11, hawaii
  z11) = `marginal` (fruits, carries calendar); the temperate + warm core (z5-z10 across most
  regions) = `fruits_reliably`. **No `survives_no_fruit` cells were used**, so the A3 chill
  no-fruit split (which reads the shared `region_chill_delivered` table against the min-variety-chill
  floor) never triggers -- correct for a low-chill species where chill is rarely the limiter.

## Other refits from peach
- **Very easy, few pests.** Pests: birds (severity high -- the main competitor, framed as a feature
  since mulberry is a top wildlife tree), whiteflies (low), borers (low, secondary on stressed
  trees). Diseases: popcorn disease (Ciboria carunculoides, medium, southern/white-type), bacterial
  blight (Pseudomonas syringae pv. mori, low), minor leaf spots/mildews (low). No spray program.
- **The mess/staining is a real siting note**, threaded through companions (bad_seasoned:
  "Walkways, patios, driveways, and parking under the canopy", extension_backed/high), the
  `mulberry_fd_stains` diagnostic, planting tips, and notifications. Both UF/IFAS and NC State
  explicitly warn against planting over pavement.
- **Vigor / size / rootstock handled honestly.** Standard tree 30-60 ft, spacing [300,360] in;
  `container_ok=false` (dwarf/weeping types are the container route). Unlike peach's soil-pest
  rootstock system, mulberry has NO size/pest rootstock: `recommended_rootstock = "own-root or Morus
  seedling"`, `rootstock_selection_basis = "own_root_or_seedling"`; rootstock_options = own-root
  (hardwood cutting), Morus seedling (propagation only, not dwarfing), and genetic dwarf (Dwarf
  Everbearing) as the container route.
- **Fast + young-bearing + long-lived:** `years_to_first_harvest [2,3]`, `years_to_full_production
  [4,6]`, `productive_lifespan_years 75`. **Extreme perishability + heavy yield:** `harvest_urgency
  high`; storage emphasizes eat/refrigerate/freeze same day (why mulberries are never a grocery
  fruit); yield "far more than a household can use." **No thinning** (fruit_set stage is
  fruit-development, not thin). Pruning is LIGHT and done in **deep dormancy** (`pruning_window`
  Jan-Feb) because mulberry bleeds sap heavily if cut in growth.
