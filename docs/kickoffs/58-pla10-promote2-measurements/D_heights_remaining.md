## Method

- URLs: every `url` under any key ending `anchoring_urls` anywhere in the crop record (crop root, entries, varieties, etc.).
- Evidence: raw bytes only -- `tools/.doc_cache/<sha1(url)>.txt` and `tools/.evidence_cache/<sha256>.<ext>` via MANIFEST.tsv url column; PDFs via `pla10_promote_common.pdf_text`; text via `norm_text` (script/style stripped first). No fetches.
- Scan 1: number+unit (ft/feet/inch/in./") within ~50 chars of tall/height/grows to/reaches N, or 'N <unit> high' -> 843 unique hits, all read. Scan 2 (broader verbs: grow/plants are/reach/stalk...) and scan 3 (adjectival '6- to 8-foot plants', 'N-inch tall') over every crop, read for crops without a finding. Targeted crop-keyword reads for every NONE crop.
- Every quote below was re-checked as an exact substring of the crop's own cited cached bytes (normalized, lowercase) by script: 0 misses. A quote in the TSV is `norm_text` form (lowercased).
- Classes: STATES-CLOSED = a closed range/point for the crop (as a single statement). CONDITIONAL = only cultivar/type/rootstock/stage-conditional figures or open bounds -> authors null. SCOPE-DOUBT = the only height sentence is about a different taxon/form on a page the crop cites. NONE = no plant-height statement in cached cited pages (counts given).
- Not counted as plant height: seedling/transplant/harvest-stage/side-dress heights, pest/fruit/leaf lengths, raised-bed, cage, stake, trellis, fence heights, pruning/topping heights, vine run (§4.5).
